Kode ini merupakan simulasi Sistem Informasi Perpustakaan berbasis terminal yang diawali dengan sistem Login pustakawan dan pendaftaran data awal untuk katalog buku. Di dalam dasbor utamanya, program ini mengimplementasikan algoritma Bubble Sort untuk mengurutkan judul buku, Sequential Search untuk pencarian data, serta struktur data Stack (LIFO) untuk mengelola tumpukan pengembalian dan Queue (FIFO) untuk antrean pemeriksaan buku. Seluruh alur kerja tersebut dibungkus dalam sebuah menu interaktif yang akan terus berjalan hingga pengguna memilih untuk menutup sistem.
